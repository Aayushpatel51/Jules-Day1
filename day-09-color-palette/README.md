# Day 09: Color Palette Generator

A vibrant and interactive color palette generator built with Vanilla JavaScript and Tailwind CSS.

## Features
- **Instant Generation:** Press the **Spacebar** or click the button to generate a new 5-color palette.
- **Locking System:** Lock individual colors you like, and only the unlocked ones will change on the next generation.
- **Click to Copy:** Simply click any color card to copy its Hex code to your clipboard.
- **Aesthetic UI:** Large, immersive color cards with smooth transitions and a clean dark mode.
- **Toast Notifications:** Feedback when a color is successfully copied.

## Tech Stack
- **HTML5**
- **Tailwind CSS** (via CDN)
- **Lucide Icons** (via CDN)
- **Vanilla JavaScript**

## How to Run
Simply open `index.html` in any modern web browser.
