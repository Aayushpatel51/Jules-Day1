# Day 10: Markdown Previewer

A professional-grade, aesthetic markdown previewer built with Vanilla JavaScript and Tailwind CSS.

## Features
- **Real-time Preview:** As you type, the preview pane updates instantly.
- **Full Markdown Support:** Handles headers, lists, links, images, blockquotes, and code blocks using `marked.js`.
- **Character Count:** Keep track of your content length.
- **Persistence:** Automatically saves your work to LocalStorage.
- **Export to HTML:** Export your rendered markdown as a standalone HTML file.
- **Aesthetic UI:** Split-screen glassmorphism design with a dark mode toggle.

## Tech Stack
- **HTML5**
- **Tailwind CSS** (via CDN)
- **Lucide Icons** (via CDN)
- **Marked.js** (via CDN)
- **Vanilla JavaScript**

## How to Run
Simply open `index.html` in any modern web browser.
