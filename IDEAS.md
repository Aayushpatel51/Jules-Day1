# 30-Day Coding Challenge: Ideas List

This list contains 30 ideas ranging from beginner to advanced, focusing on mini-products that are visually appealing for Instagram.

## Phase 1: Beginner (Days 1-10)

### Day 01: Personal Portfolio Landing Page
- **Description:** A simple, responsive landing page to showcase your work and skills.
- **Tech Stack:** HTML, CSS (Flexbox/Grid).
- **Instagram Tip:** Record a "scroll-through" of the page showing the responsive layout.

### Day 02: Pomodoro Timer
- **Description:** A productivity timer with work and break intervals.
- **Tech Stack:** JavaScript, HTML, CSS.
- **Instagram Tip:** A time-lapse of the timer counting down or a carousel showing "Work" vs "Break" states.

### Day 03: Weather App
- **Description:** Displays current weather based on user location or city search.
- **Tech Stack:** Vanilla JavaScript, Open-Meteo API.
- **Instagram Tip:** Show different UI backgrounds for different weather conditions (Sunny vs Rainy).

### Day 04: To-Do List with LocalStorage
- **Description:** A task manager that persists data even after refreshing the page.
- **Tech Stack:** Vue.js or React.
- **Instagram Tip:** A screen recording of adding, completing, and deleting tasks.

### Day 05: Random Quote Generator
- **Description:** Fetches and displays inspiring quotes with a "Tweet this" button.
- **Tech Stack:** JavaScript (Fetch API), Tailwind CSS.
- **Instagram Tip:** Use a stylish typography layout and change colors on every new quote.

### Day 06: Unit Converter
- **Description:** Converts Length, Weight, or Temperature.
- **Tech Stack:** HTML, CSS, JavaScript.
- **Instagram Tip:** Show the instant conversion as the user types.

### Day 07: Simple Calculator
- **Description:** A fully functional calculator with basic arithmetic.
- **Tech Stack:** JavaScript, CSS Grid.
- **Instagram Tip:** Highlight the button click animations and the "Glassmorphism" design.

### Day 08: Digital Clock & Stopwatch
- **Description:** A clean digital clock with a stopwatch feature.
- **Tech Stack:** JavaScript, CSS.
- **Instagram Tip:** A side-by-side of the live clock and the stopwatch laps.

### Day 09: Color Palette Generator
- **Description:** Generates random color schemes and allows users to copy hex codes.
- **Tech Stack:** JavaScript.
- **Instagram Tip:** A reel showing rapid generation of beautiful color palettes.

### Day 10: Markdown Previewer
- **Description:** A split-screen editor that renders Markdown in real-time.
- **Tech Stack:** React, Marked.js.
- **Instagram Tip:** Show "Code on the left, Preview on the right" side-by-side.

---

## Phase 2: Intermediate (Days 11-20)

### Day 11: Recipe Search App
- **Description:** Search for recipes by ingredients and display nutritional info.
- **Tech Stack:** React, Edamam API.
- **Instagram Tip:** Showcase the card grid layout with high-quality food images.

### Day 12: Expense Tracker with Charts
- **Description:** Log income/expenses and visualize them with a pie chart.
- **Tech Stack:** JavaScript, Chart.js.
- **Instagram Tip:** Show the chart dynamically updating when a new expense is added.

### Day 13: GitHub Profile Finder
- **Description:** Enter a username to see GitHub stats, repos, and followers.
- **Tech Stack:** React, GitHub API.
- **Instagram Tip:** Compare your own profile with a famous developer's profile.

### Day 14: URL Shortener UI
- **Description:** A clean interface to shorten long URLs (can use a mock backend).
- **Tech Stack:** Next.js, Tailwind CSS.
- **Instagram Tip:** Show the "Before" (long URL) and "After" (short URL) transition.

### Day 15: Quiz App with Categories
- **Description:** A multiple-choice quiz with a score tracker at the end.
- **Tech Stack:** React, OpenDB API.
- **Instagram Tip:** Record the "Success" and "Failure" animations for answers.

### Day 16: Habit Tracker
- **Description:** Track daily habits with a 7-day progress view.
- **Tech Stack:** React, Firebase or LocalStorage.
- **Instagram Tip:** Show the progress "streaks" or checkmarks filling up.

### Day 17: Password Manager/Generator
- **Description:** Generate secure passwords and store them (locally) with encryption basics.
- **Tech Stack:** Node.js (Crypto), React.
- **Instagram Tip:** Show a "Strength Meter" that changes color as the password gets stronger.

### Day 18: Movie Database
- **Description:** Browse trending movies, view ratings, and watch trailers.
- **Tech Stack:** React, TMDB API, Framer Motion.
- **Instagram Tip:** Showcase smooth hover effects on movie posters.

### Day 19: Chat App UI
- **Description:** A responsive, modern chat interface with sidebar and message bubbles.
- **Tech Stack:** Tailwind CSS, React.
- **Instagram Tip:** Demonstrate the mobile responsiveness and dark mode toggle.

### Day 20: Notes App with Markdown Support
- **Description:** Create, edit, and delete notes with rich text/markdown formatting.
- **Tech Stack:** React, Lucide Icons.
- **Instagram Tip:** Show the "Auto-save" feature in action.

---

## Phase 3: Advanced (Days 21-30)

### Day 21: Real-time Chat App
- **Description:** A functional chat room using WebSockets.
- **Tech Stack:** Node.js, Socket.io, React.
- **Instagram Tip:** Open two browser windows and show messages appearing instantly in both.

### Day 22: E-commerce Product Page
- **Description:** A product page with image gallery, size picker, and cart logic.
- **Tech Stack:** Next.js, Framer Motion.
- **Instagram Tip:** Focus on the "Add to Cart" animation and image zoom.

### Day 23: Dashboard with Real-time Data
- **Description:** An admin dashboard with live data updates (stocks or crypto).
- **Tech Stack:** Next.js, Supabase, Recharts.
- **Instagram Tip:** A reel showing the live line graphs moving in real-time.

### Day 24: Social Media Feed Clone
- **Description:** A feed with post cards, infinite scroll, and "Like" interactions.
- **Tech Stack:** React, Tailwind CSS, Intersection Observer API.
- **Instagram Tip:** Show the smooth infinite scroll and heart animation.

### Day 25: Auth System (JWT/NextAuth)
- **Description:** Complete Login/Signup flow with protected routes.
- **Tech Stack:** Next.js, NextAuth.js, MongoDB.
- **Instagram Tip:** Show the transition from "Logged Out" state to "Dashboard" after login.

### Day 26: File Uploader with Progress Bar
- **Description:** Upload images to a cloud service with a visual progress bar.
- **Tech Stack:** React, Cloudinary or S3.
- **Instagram Tip:** A screen recording of the progress bar filling up and the image appearing.

### Day 27: Cryptocurrency Tracker
- **Description:** Track top 50 cryptos with live prices and 24h change.
- **Tech Stack:** React, CoinGecko API.
- **Instagram Tip:** Highlight the Green/Red color coding for price changes.

### Day 28: Blog CMS
- **Description:** A blog that fetches content from a headless CMS.
- **Tech Stack:** Next.js, Contentful or Sanity.io.
- **Instagram Tip:** Show yourself updating a post in the CMS and it reflecting on the site instantly.

### Day 29: AI Image Generator Interface
- **Description:** A UI to input prompts and display AI-generated images.
- **Tech Stack:** React, OpenAI DALL-E API.
- **Instagram Tip:** Show the "Prompt to Image" process—very viral-friendly!

### Day 30: Full-stack SaaS Landing Page
- **Description:** A complete landing page with pricing, features, and mock checkout.
- **Tech Stack:** Next.js, Tailwind, Stripe (Test Mode).
- **Instagram Tip:** A high-speed montage of all 30 days, ending with this final product.
