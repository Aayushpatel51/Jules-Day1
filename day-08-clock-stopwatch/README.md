# Day 08: Digital Clock & Stopwatch

A clean, aesthetic digital clock and stopwatch built with Vanilla JavaScript and Tailwind CSS.

## Features
- **Real-time Clock:** Displays local time with seconds and current date.
- **Stopwatch:** Accurate to hundredths of a second.
- **Laps:** Record multiple laps during stopwatch use.
- **Responsive Design:** Beautifully optimized for mobile and desktop.
- **Light/Dark Mode:** Toggle between themes seamlessly.
- **Aesthetic UI:** Uses glassmorphism and modern typography.

## Tech Stack
- **HTML5**
- **Tailwind CSS** (via CDN)
- **Lucide Icons** (via CDN)
- **Vanilla JavaScript**

## How to Run
Simply open `index.html` in any modern web browser.
